### Callout UI with `offset-path: border-box` and Container Queries
### 用 `offset-path: border-box` 與容器查詢做 callout UI

[原文連結](https://frontendmasters.com/blog/callout-ui-with-css-offset-border/)

- **Goal**
  - Annotation callouts where a leader line and its attached text box stay glued together as the layout changes.
- **Technique**
  - The container provides the leader line via `border` (e.g. `border-width: 0 2px 2px 0` dashed).
  - The text box rides the border using `offset-path: border-box` + `offset-anchor` + `offset-distance: 100cqw`.
  - `container-type: size` lets `cqw` measure against the callout, not the viewport.
- **Bonus**
  - Composes naturally with `border-radius`, `corner-shape`, skew, animations, shadows — variants drop in with one extra rule.
-------
- **目標**
  - 註解式 callout：引導線與其文字框在布局變動時仍能維持「綁在一起」。
- **技巧**
  - 容器用 `border` 提供引導線（例如 `border-width: 0 2px 2px 0` 虛線）。
  - 文字框透過 `offset-path: border-box` + `offset-anchor` + `offset-distance: 100cqw` 沿著 border 移動。
  - `container-type: size` 讓 `cqw` 以 callout 自身寬度計算，而非 viewport。
- **延伸**
  - 自然搭配 `border-radius`、`corner-shape`、skew、動畫、陰影 — 一條額外規則就能做變體。

### Python 3.14.5 Reverts the Incremental GC Introduced in 3.14
### Python 3.14.5 把 3.14 推出的「增量 GC」還原回去

[Release Notes](https://www.python.org/downloads/release/python-3145/)

- **What got reverted**
  - The incremental garbage collector shipped in 3.14.0–3.14.4 is reverted to 3.13's generational collector after multiple reports of significant memory pressure in production.
- **Other changes in 3.14.5**
  - macOS installer bumps to Tcl/Tk 9.0.3; ~154 bug-fixes and doc improvements since 3.14.4; new Windows install manager via the Microsoft Store.
- **Context — what 3.14 still includes**
  - Free-threaded Python, deferred annotation evaluation, t-strings, Zstandard, experimental JIT in official binaries, plus Python's move from PGP signatures to Sigstore.
- **Release date**: May 10, 2026.
-------
- **被還原的東西**
  - 3.14.0–3.14.4 推出的增量 GC 在收到多次生產環境記憶體壓力回報後，被還原成 3.13 的世代式 GC。
- **3.14.5 的其他變動**
  - macOS installer 升級到 Tcl/Tk 9.0.3；自 3.14.4 起累積約 154 個 bug 修補與文件改善；Windows 透過 Microsoft Store 提供新的安裝管理員。
- **背景 — 3.14 仍保留的特性**
  - free-threaded Python、延遲註解求值、t-string、Zstandard 壓縮、官方 binary 內的實驗 JIT，以及 Python 從 PGP 簽章改用 Sigstore 驗證。
- **發布日期**：5/10。

## Glossary

- **Agent Skills (open standard)**
  - A community convention for packaging reusable agent capabilities as folders containing a `SKILL.md` plus examples — so the same skill works across Claude Code, Cursor, Codex, etc.
  - 把可重用 agent 能力打包成「資料夾 + `SKILL.md` + 範例」的社群規格 — 同一個 skill 能跨 Claude Code、Cursor、Codex 使用。
- **`offset-path` (CSS)**
  - A property that defines a path an element follows; combined with `offset-anchor` and `offset-distance` it lets you ride a specific anchor along a path (here, the parent's `border-box`).
  - CSS 屬性，定義元素跟隨的路徑；搭配 `offset-anchor` 與 `offset-distance` 可讓特定錨點沿路徑（這裡是父元素的 `border-box`）移動。
- **`cqw` / `cqh` (container query units)**
  - CSS length units that measure against the container's inline-size or block-size, not the viewport — required for true component-driven responsive design.
  - 以容器的 inline-size 或 block-size（而非 viewport）為基準的 CSS 長度單位 — 真正以元件為單位做 RWD 的關鍵。
- **Copy-on-write (CoW)**
  - A storage technique where a "clone" initially shares physical pages with its source; only modified pages get duplicated — makes clones cheap and fast.
  - 一種儲存技巧：clone 起初與來源共用實體頁，只有被修改的頁才會被複製出來 — clone 因此又便宜又快。
- **Incremental GC**
  - A garbage collector that does small amounts of work each cycle instead of one big stop-the-world pass — trades total throughput for lower max pause times.
  - 把垃圾回收切成每輪少量工作、而非一次 stop-the-world 大掃描的 GC — 拿總體吞吐量換更低的最長暫停時間。
- **Generational GC**
  - The opposite design: organise objects by age and collect young objects more often. Cheaper for typical allocation patterns; what Python 3.13 used and 3.14.5 fell back to.
  - 與增量 GC 相反的設計：把物件依年齡分代、年輕物件更常被回收。對典型分配模式較便宜；Python 3.13 用的、3.14.5 也退回這個方案。
- **Sigstore**
  - A free signing service that issues short-lived certificates tied to OIDC identities; replaces long-lived PGP keys for verifying release artifacts.
  - 一個免費簽章服務，會發行短命且綁定 OIDC 身分的憑證；用於驗證 release artifact，取代長壽 PGP 金鑰。
- **t-string (template string)**
  - A new Python 3.14 string type that stays as a template (with the raw parts and placeholders accessible) instead of being eagerly interpolated — useful for safe SQL, HTML, and prompt building.
  - Python 3.14 推出的新字串型別，會保留為模板（可拿到原始片段與插值點），而非被立即填值 — 用在安全的 SQL、HTML、prompt 組合特別有用。
- **ONNX Runtime**
  - A cross-platform inference engine for models exported to the ONNX format; lets one model file run on CPU, GPU, mobile, browser via the same runtime.
  - 跨平台的 ONNX 格式模型推理引擎；同一份模型檔可在 CPU、GPU、行動裝置、瀏覽器透過同一個 runtime 跑。
