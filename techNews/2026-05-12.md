### TanStack npm Supply-Chain Compromise: 42 Packages, 84 Malicious Versions
### TanStack npm 供應鏈攻擊：42 個套件、84 個惡意版本

[Postmortem 連結](https://tanstack.com/blog/npm-supply-chain-compromise-postmortem)

- **What happened**
  - May 11, 19:20–19:26 UTC: attacker chained "pull request target" Actions pattern + cache poisoning across trust boundaries + OIDC token extraction from runner memory.
  - 42 packages across `@tanstack/*` got 84 malicious versions published; new versions appeared every ~6 minutes across two workflow runs.
  - Detected by external researchers within ~20 minutes.
- **What's safe**
  - `@tanstack/query`, `@tanstack/table`, `@tanstack/form`, `@tanstack/virtual`, `@tanstack/store`, `@tanstack/start` — not affected.
- **What the malware did**
  - Harvested AWS, GCP, Kubernetes, Vault, GitHub tokens, SSH keys; exfiltrated over encrypted Session/Oxen networks; self-propagated by republishing other packages the victim maintains.
- **Required action**
  - If you ran `npm install` against affected versions on May 11, rotate AWS / GCP / Kubernetes / Vault / GitHub / npm / SSH credentials reachable from the install host.
-------
- **發生什麼**
  - 5/11 19:20–19:26 UTC：攻擊者串接「pull request target」Actions 模式 + 跨信任邊界的快取毒化 + 從 runner 記憶體抽出 OIDC token。
  - `@tanstack/*` 命名空間下 42 個套件被推上 84 個惡意版本；兩次工作流跑下來每約 6 分鐘出一個新版。
  - 外部研究者約 20 分鐘內偵測到。
- **沒被波及的**
  - `@tanstack/query`、`@tanstack/table`、`@tanstack/form`、`@tanstack/virtual`、`@tanstack/store`、`@tanstack/start` — 未受影響。
- **惡意程式做了什麼**
  - 偷 AWS、GCP、Kubernetes、Vault、GitHub token、SSH key；走加密的 Session／Oxen 網路外送；並把受害者維護的其他套件也改投惡意版本以擴散。
- **必須做的事**
  - 若 5/11 對受影響版本跑過 `npm install`：把 install 主機可觸及的 AWS／GCP／Kubernetes／Vault／GitHub／npm／SSH 憑證全部輪換。

### JavaScript Composites Proposal: Compare Two Objects with Same Shape and Get `true`
### JavaScript Composites 提案：比較兩個內容相同的物件可以得 `true` 了

[Chris Coyier 文章](https://frontendmasters.com/blog/arrays-objects-now-composites/)

- **The problem**
  - Today: `{x:1,y:4} === {x:1,y:4}` returns `false`, and you can't use plain objects as `Map` keys for value-equality lookups.
- **The proposal**
  - TC39 proposal for an immutable, value-based composite type:
    ```js
    const a = Composite({ x: 1, y: 4 });
    const b = Composite({ x: 1, y: 4 });
    Composite.equal(a, b); // true
    ```
  - Equality is shape-and-value, regardless of property order.
- **Why now**
  - Records & Tuples (the older proposal) hit performance concerns. Composites is the lighter alternative that's getting more traction.
- **Status**
  - Still early; "discussion and research going on" — don't expect it in the language soon, but worth tracking if you've ever passed objects as cache keys.
-------
- **問題**
  - 現況：`{x:1,y:4} === {x:1,y:4}` 回傳 `false`，而且純物件不能拿來當 `Map` 的 key 做「值相等」查詢。
- **提案**
  - TC39 提案：不可變、以值為基底的 composite 型別：
    ```js
    const a = Composite({ x: 1, y: 4 });
    const b = Composite({ x: 1, y: 4 });
    Composite.equal(a, b); // true
    ```
  - 相等性比較看結構與值，不在意屬性順序。
- **為什麼是現在**
  - 較早的 Records & Tuples 卡在效能問題。Composites 是更輕量的替代方案，目前進展較佳。
- **狀態**
  - 還在早期；「仍在討論與研究」 — 短期內不會進語言，但若你曾用物件當快取 key 就值得追蹤。

### Building a UI Without Breakpoints
### 沒有 breakpoint 也能做 RWD

[原文連結](https://frontendmasters.com/blog/building-a-ui-without-breakpoints/)

- **Philosophy**
  - Build fluid, intrinsic components by default; treat conditional rules as local, intentional exceptions — not the layout engine.
- **CSS tools used**
  - **Intrinsic grids**: `auto-fit` + `minmax()` for self-adapting columns; flexbox `flex-wrap` for two-region layouts.
  - **Fluid functions**: `clamp()`, `min()`, `max()` for typography, spacing, sizing — no discrete breakpoints.
  - **Container queries**: container inline-size units (`cqi`) and `@container` rules to scale based on component width, not viewport.
  - **Media queries refined**: keep them for `hover`, `pointer`, `prefers-reduced-motion`, `prefers-color-scheme` — i.e. capabilities and preferences, not layout.
-------
- **核心理念**
  - 預設用流體、本身會適應的元件構建；條件規則只當作「局部、有意為之的例外」，而不是布局的主引擎。
- **使用的 CSS 工具**
  - **內在格線**：`auto-fit` + `minmax()` 做自動適應欄數；flexbox `flex-wrap` 處理兩區布局。
  - **流體函式**：`clamp()`、`min()`、`max()` 做字級、間距、尺寸 — 不用離散斷點。
  - **容器查詢**：用容器寬度單位 `cqi` 與 `@container`，依元件寬度而非視窗縮放。
  - **重新定位 media query**：留給 `hover`、`pointer`、`prefers-reduced-motion`、`prefers-color-scheme` 等「能力與偏好」，而不是布局。

## Glossary

- **Supply-chain attack**
  - An attack where the attacker compromises a trusted dependency (npm package, container image, build tool) so the malware spreads automatically to everyone who installs that dependency.
  - 攻擊者藉由污染一個被信任的依賴（npm 套件、container image、build 工具），讓惡意程式自動擴散到所有安裝該依賴的人。
- **OIDC token (in CI context)**
  - A short-lived identity token issued by the CI platform to authenticate to external systems (npm, AWS, GCP) — designed to replace long-lived secrets. Extracting it from runner memory bypasses normal publish safeguards.
  - CI 平台簽發、給外部系統（npm、AWS、GCP）認證用的短命身分 token — 設計上要取代長期 secret。若從 runner 記憶體中拔出來就能繞過正常發布防護。
- **`pull_request_target` (GitHub Actions)**
  - A workflow trigger that runs in the *base* repository's context with full secrets, even for PRs from forks — historically a source of supply-chain incidents because forked code can sometimes execute with elevated trust.
  - 一種 GitHub Actions 觸發類型，即使 PR 來自 fork 也會在「主 repo」context 下執行並擁有完整 secret — 過往多次供應鏈事件的源頭，因為 fork 程式碼可能在較高信任層級下執行。
- **Managed Agents (Anthropic)**
  - Anthropic-hosted infrastructure for running long-lived Claude agents — handles state, retries, scaling — so you don't run the agent loop yourself.
  - Anthropic 託管的長壽 Claude agent 執行基礎設施 — 處理狀態、重試、擴容 — 讓你不必自己跑 agent 迴圈。
- **Advisor strategy (Anthropic)**
  - A beta strategy that adds a stronger model to consult during a weaker model's reasoning — improving agent quality without paying for the strong model on every step.
  - Beta 策略：在較弱模型推理過程中讓更強的模型介入諮詢 — 在不必每步都付強模型費用的前提下提升 agent 品質。
- **Composite (TC39 proposal)**
  - A proposed immutable JS value with structural equality — `Composite({a:1}) === Composite({a:1})` semantics, suitable for use as `Map` keys.
  - 一個提議中的 JS 不可變值，比較時走結構相等 — 例如 `Composite({a:1}) === Composite({a:1})`，可拿來當 `Map` 的 key。
- **Container query**
  - A CSS feature that lets a component style itself based on its *own* available width, not the viewport — required for true component-driven responsive design.
  - 一個 CSS 功能，讓元件依「自身可用寬度」而非視窗寬度套用樣式 — 真正以元件為單位做 RWD 的關鍵。
- **`cqi` (container query inline-size)**
  - A CSS length unit equal to 1% of the container's inline size (usually width) — letting you do fluid sizing relative to the parent container instead of viewport.
  - 一個 CSS 長度單位，等於容器 inline 方向尺寸（通常是寬度）的 1% — 讓尺寸隨父容器（而非視窗）做流體縮放。
- **SBOM (Software Bill of Materials)**
  - A machine-readable inventory of every dependency and version in a piece of software — increasingly required for supply-chain attestation and incident response.
  - 列出一個軟體所有依賴與版本的機器可讀清單 — 在供應鏈 attestation 與事件回應中越來越是必要產物。
