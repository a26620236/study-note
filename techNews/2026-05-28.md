### Why Ctrl+V Won't Paste Images in Claude Code on WSL (with Fix)
### 為什麼在 WSL 的 Claude Code 按 Ctrl+V 貼不上圖片（含解法）

[原文連結](https://rajveerbachkaniwala.com/blog/2026/05/24/on-the-difficulty-of-pasting-a-picture/)

- **The symptom**
  - Copy an image in Windows → Ctrl+V in Claude Code under WSL inside Windows Terminal → silently nothing.
- **Three independent bugs stacking**
  - **WSLg format conversion**: the Windows→Linux clipboard bridge only ships an old BMP variant with obscure colour encoding; Claude Code can't parse it.
  - **Silent overwrite**: workaround of placing a PNG on the Linux clipboard gets immediately overwritten — WSLg syncs to Windows, then re-syncs the broken BMP back to Linux.
  - **Windows Terminal interception**: Ctrl+V is consumed by the terminal as "paste text", never reaches the app.
- **The fix**
  - `clip-listener.exe` on Windows converts clipboard images to PNG via GDI+.
  - `wsl-clip-bridge` script in Linux re-asserts the PNG after WSLg overwrites.
  - Rebind to **Alt+V** inside Claude Code config so it bypasses Windows Terminal.
- **Why it's worth reading**
  - A clean dissection of how three subtly-broken systems combine to silently kill a feature — the same shape as 80% of production agent bugs.
-------
- **症狀**
  - Windows 複製圖片 → 在 Windows Terminal 內的 WSL Claude Code 按 Ctrl+V → 完全沒反應、沒提示。
- **三個獨立 bug 疊一起**
  - **WSLg 格式轉換**：Windows→Linux 剪貼簿橋接只支援一種冷僻配色的舊版 BMP；Claude Code 不會解析。
  - **靜默覆蓋**：就算手動把 PNG 放到 Linux 剪貼簿，也會立刻被覆蓋 — WSLg 把它同步回 Windows、再把壞掉的 BMP 同步回 Linux。
  - **Windows Terminal 攔截**：Ctrl+V 被終端機當「貼文字」吃掉，根本沒傳到應用層。
- **解法**
  - Windows 端跑 `clip-listener.exe`，用 GDI+ 把剪貼簿圖片轉成 PNG。
  - Linux 端 `wsl-clip-bridge` 在 WSLg 覆蓋後重新把 PNG 寫回剪貼簿。
  - Claude Code 設定裡改綁 **Alt+V**，繞過 Windows Terminal 的攔截。
- **為什麼值得讀**
  - 一篇乾淨的「三個各自有點壞的系統，疊起來悄悄殺掉一個功能」拆解 — 80% 的 production agent bug 都是這個形狀。

### CSS Anchor Positioning Without the HTML `anchor` Attribute
### CSS Anchor Positioning 不靠 HTML `anchor` 屬性也能做

[原文連結](https://frontendmasters.com/blog/managing-anchor-associations-with-data-attributes-and-advanced-attr/)

- **Background**
  - CSS anchor positioning ties a "boat" element to an "anchor" element via `position-anchor` and `anchor-name`. Chrome shipped an `anchor` HTML attribute for this, but it wasn't standardised and got removed.
- **The trick: `data-` + advanced `attr()`**
  - ```html
    <div data-boat="--anchorA">Boat A</div>
    <div data-anchor="--anchorA">Anchor A</div>
    ```
  - ```css
    [data-boat] {
      position: fixed;
      inset: anchor(top) auto auto anchor(right);
      position-anchor: attr(data-boat type(<custom-ident>));
    }
    [data-anchor] {
      anchor-name: attr(data-anchor type(<custom-ident>));
    }
    ```
  - The `type(<custom-ident>)` argument is what makes advanced `attr()` "advanced" — it casts the attribute as a dashed ident, not a plain string.
- **Browser support**
  - Chrome: already supports it. Firefox 152: ships **2026-06-16**. Safari: in Technology Preview; stable ETA September 2026.
- **Coming next**
  - A future `ident()` CSS function will let you drop the dashed-ident convention in HTML — but it's not implemented yet.
-------
- **背景**
  - CSS anchor positioning 透過 `position-anchor` 與 `anchor-name` 把「船」綁到「錨」上。Chrome 原本有出過 HTML 端的 `anchor` 屬性，但因未進標準被移除。
- **新做法：`data-` 屬性 + advanced `attr()`**
  - ```html
    <div data-boat="--anchorA">Boat A</div>
    <div data-anchor="--anchorA">Anchor A</div>
    ```
  - ```css
    [data-boat] {
      position: fixed;
      inset: anchor(top) auto auto anchor(right);
      position-anchor: attr(data-boat type(<custom-ident>));
    }
    [data-anchor] {
      anchor-name: attr(data-anchor type(<custom-ident>));
    }
    ```
  - 關鍵的「advanced」就在 `type(<custom-ident>)` — 它把屬性值當成 dashed ident，而不是普通字串。
- **瀏覽器支援**
  - Chrome：已支援。Firefox 152：將於 **2026-06-16** 釋出。Safari：Technology Preview 已支援；穩定版預估 9 月。
- **後續**
  - 規劃中的 `ident()` CSS function 會讓你不必再加 dashed 前綴 — 但目前還沒實作。

### `toastr-next v3`：零依賴復活 12k 星的舊 library

  - Preserved the original surface (`success`, `error`, `info`, `warning`) so existing calls keep working; new async patterns added on top.
-------
- **為什麼要復活**
  - 原版 `toastr`：12k 星、自 2016 年起無人維護；依賴 jQuery（~87KB）；不支援 TypeScript、沒 dark mode、沒 a11y；build 系統是已死的 Gulp+LESS。

  - 完全用 TypeScript 重寫、**零依賴**。~4KB gzipped，原本要 ~87KB。
  - 原生 CSS 動畫（不靠 jQuery）、自動注入 CSS。
  - Promise-based：`await toast.dismissed`。
  - 內建 `prefers-color-scheme` dark mode。
  - 符合 WCAG 2.1 AA — 正確 ARIA role、支援 Esc／Tab 鍵盤操作、RTL、會尊重 `prefers-reduced-motion`。
- **打包格式**
  - ESM、CJS、UMD、IIFE。提供 `useToastr` hook 原生接 React。
- **遷移**
  - 保留原本的 API（`success`、`error`、`info`、`warning`），舊呼叫不必改；async 用法是「新增」、不是取代。

### Go: Generic Methods Accepted for Go 1.27
### Go：Generic Method 提案通過、預計進 Go 1.27

[GitHub 連結](https://github.com/golang/go/issues/77273)

- **What's the gap**
  - Today methods can only use type parameters declared on their receiver type — they can't have their own. Forces awkward workarounds when you want a method that's polymorphic in something other than the receiver.
- **The historical "no"**
  - The Go team previously said generic methods would force generic *interface* methods, which would break Go's implicit-interface-satisfaction model (compiler doesn't know what to instantiate). The original Type Parameters Proposal FAQ said: "we do not anticipate that Go will ever add generic methods."
- **The new "yes"**
  - Status: **Proposal-Accepted**, milestone Go 1.27.
  - Syntax mirrors generic functions:
    ```go
    type Reader struct{ … }
    func (*Reader) Read[E any]([]E) (int, error) { … }
    ```
  - Type inference works as with generic functions.
- **Why it matters**
  - Cleans up libraries that today fake generic methods via top-level generic functions taking the receiver as a parameter. Signals the Go team is willing to walk back hard "never" statements when usage data justifies it.
-------
- **目前的缺口**
  - Method 目前只能用 receiver 型別宣告的 type parameter，不能有自己的。當你想要「多型在 receiver 以外的某個型別」時，得繞遠路。
- **官方曾說「不會」**
  - Go team 原本認為 generic method 會逼著也要支援 generic *interface* method，那會破壞 Go 的「隱式介面實作」模型（編譯器不知道要 instantiate 哪些版本）。原 Type Parameters Proposal 的 FAQ 明寫：「我們不認為 Go 會加 generic method」。
- **現在說「會」**
  - 狀態：**Proposal-Accepted**，目標版本 Go 1.27。
  - 語法跟 generic function 一致：
    ```go
    type Reader struct{ … }
    func (*Reader) Read[E any]([]E) (int, error) { … }
    ```
  - Type inference 跟 generic function 一樣運作。
- **為什麼有意義**
  - 清掉一堆 library 今天得用「receiver 當參數的 top-level generic function」假裝 generic method 的醜寫法。也代表 Go team 願意在使用數據夠強時，推翻原本「永不」的硬話。

## Glossary

- **Tokenmaxxing**
  - The discipline of squeezing the most useful work out of the fewest tokens — model selection by task tier, context trimming, caching, plan-tiering. The post-honeymoon mode of using AI agents at scale.
  - 用最少 token 榨出最多有用工作的紀律 — 按任務分級選模型、修剪 context、做快取、訂閱方案分級。AI agent 大規模使用「蜜月期結束後」的常態。
- **Style-neutral framework**
  - A UI framework whose core has no opinion on visual design — themes / design systems are loaded as optional layers. Makes it easy for an agent to dress the same UI tree in many ways.
  - 核心不對視覺風格持立場的 UI 框架 — design system 是可選的外掛層。同一個 UI tree 可以被 agent 套上不同打扮。
- **WebMCP**
  - A pattern where a website exposes its capabilities as MCP tools in parallel to its HTML pages — humans use the page, agents call the tools. Same backend, two surfaces.
  - 一種模式：網站把自己的能力以 MCP tool 形式暴露出來，與 HTML 頁面並存 — 人用頁面、agent 呼叫 tool。同一個後端、兩個介面。
- **Source-of-truth contract (claude-code-harness)**
  - A discipline where the spec file is treated as the binding record of what's to be built — the agent can't silently invent or expand scope mid-task. Drift is detected by diffing against the spec.
  - 一種紀律：spec 檔被當成「要做什麼」的最終契約 — agent 不能在執行過程中私自加 scope。差異是用「跟 spec diff」抓出來的。
- **WSLg**
  - The Windows Subsystem for Linux graphical layer — provides clipboard, display, audio bridging between Windows host and Linux guest. The shared layer at the heart of the Claude Code paste bug.
  - WSL 的 GUI 子系統，提供 Windows 主機與 Linux 客體之間的剪貼簿、顯示、音訊橋接。Claude Code 貼圖 bug 的根源就在這層。
- **Generic methods (Go)**
  - Methods that declare their own type parameters, independent of the receiver's type parameters. Closes a long-standing gap between Go's generic functions and generic types.
  - 可以自己宣告 type parameter 的 method（與 receiver 上的 type parameter 獨立）。補上 Go「generic function」與「generic type」之間的長期缺口。
- **Anchor positioning (CSS)**
  - A CSS feature pairing one element ("boat") to another ("anchor") so that the boat's position is computed relative to the anchor's rendered box — useful for tooltips, popovers, callouts.
  - 一種 CSS 功能，把一個元素（船）綁到另一個元素（錨）上，讓船的位置以錨的渲染框為基準計算 — 適合 tooltip、popover、callout。
- **`attr()` advanced**
  - The "level 5" expansion of CSS `attr()` that lets you read an HTML attribute and use it as a typed CSS value — colors, lengths, custom idents — not just strings.
  - CSS `attr()` 的 "level 5" 擴充版：能讀 HTML 屬性並把它當作具型別的 CSS 值（顏色、長度、custom ident）使用，而不只是字串。
- **Mandatory composable skills (superpowers)**
  - A model where the agent is *required* to check a skill registry before acting on certain task classes — skills aren't suggestions; they're enforced steps in the agent's loop.
  - 一種設計：agent 在某些任務類別上「必須」先查 skill 註冊表才能動作 — skill 不是建議，是 agent 迴圈裡的強制步驟。
