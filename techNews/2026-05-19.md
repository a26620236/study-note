### Modal Cuts GPU Cold Starts 40x with Checkpoint/Restore + CUDA Snapshots
### Modal 用 checkpoint/restore + CUDA snapshot 把 GPU 冷啟動砍 40 倍

[原文連結](https://modal.com/blog/truly-serverless-gpus)

- **The problem**
  - AI inference replicas typically take tens of minutes — sometimes hours waiting for GPUs — to scale up, making "serverless GPU" mostly aspirational.
- **40x improvement**
  - Replica startup: ~2,000s → ~50s.
- **Four techniques stacked**
  - LP (Linear Programming) maintains a hot GPU buffer balancing cost vs availability.
  - FUSE filesystem: lazy-loaded, tiered cache for container images.
  - C/R (Checkpoint/Restore): snapshot host process state to skip CPU-heavy init (library imports etc.).
  - CUDA-checkpoint: snapshots GPU memory + CUDA graph state — 4–10x speedup over normal CUDA init.
- **Why you care**
  - If you run LLM inference, this is the architecture pattern enabling pay-per-second pricing without warm-pool bills.
-------
- **問題**
  - AI inference replica 通常要十幾分鐘 — 等 GPU 甚至要好幾小時 — 才能 scale up，所謂「serverless GPU」一直停留在口號階段。
- **40 倍改善**
  - Replica 啟動：約 2,000 秒 → 約 50 秒。
- **四個技術疊加**
  - LP（線性規劃）維持 GPU 熱備池，在成本與可用性之間平衡。
  - FUSE filesystem：lazy load + 分層快取的 container image。
  - C/R（Checkpoint/Restore）：snapshot host process 狀態，跳過 CPU 重活如 library import。
  - CUDA-checkpoint：snapshot GPU 記憶體 + CUDA graph 狀態 — 比一般 CUDA init 快 4–10 倍。
- **為什麼你要在意**
  - 如果你跑 LLM inference，這就是讓「秒級計費」可行、不用一直開暖機 pool 的架構模式。

### Block AI Bot PR Spam with Git's `--author` Flag
### 用 Git 的 `--author` flag 擋掉 AI bot 的 PR spam

[原文連結](https://archestra.ai/blog/only-responsible-ai)

- **The pain**
  - One bounty issue: 253 comments. One feature: 27 PRs. Mostly AI-generated untested submissions burying real contributors.
- **The trick**
  - Use `git commit --author="<user>@users.noreply.github.com"` to credit an external user with a commit — GitHub now recognizes them as a "prior contributor," which gates many spam-filter behaviors.
- **The flow**
  - CAPTCHA-gated onboarding form → GitHub Action resolves user ID via API → bot commits an entry to a contributors file using their noreply email → push to main → they're whitelisted.
- **Tradeoff**
  - It's nuclear: blocks AI bots but also adds friction for legitimate first-time contributors. Worth it for repos drowning in slop.
-------
- **痛點**
  - 一個 bounty issue 收到 253 條留言。一個 feature 收到 27 個 PR。絕大多數是 AI 生成、沒測試過的內容，把真正貢獻者淹沒。
- **小技巧**
  - 用 `git commit --author="<user>@users.noreply.github.com"` 把 commit credit 給外部 user — GitHub 會把他認成「先前貢獻者」，會通過很多 spam 過濾器。
- **流程**
  - CAPTCHA onboarding 表單 → GitHub Action 用 API 查 user ID → bot 用他的 noreply email commit 一筆到 contributors 檔 → push 到 main → 他就被白名單化。
- **取捨**
  - 這招很核武：擋 AI bot 但也增加新貢獻者的摩擦。對被 AI slop 淹沒的 repo 值得。

### React Server Components Land in TanStack Start
### React Server Components 進入 TanStack Start

[原文連結](https://frontendmasters.com/blog/react-server-components-in-tanstack/)

- **Explicit API**
  - Uses `createServerFn()` and `renderServerComponent()` — declarative function calls instead of Next.js's file-based "magic" RSC discovery.
- **Component-as-prop pattern**
  - Pass React components as props to RSCs (not just data) — flexible composition, including a `CompositeComponent` wrapper for mixing server + client.
- **Real perf gain shown**
  - Demo example: JS bundle drops from 308KB → 203KB by pushing non-interactive logic server-side.
- **Server-only data**
  - RSCs can directly `await` DB calls / API requests — no intermediate API routes needed, credentials never reach the client.
- **Why this matters**
  - First serious RSC alternative outside Next.js. If you've been waiting for RSC without Next's opinionated baggage, TanStack Start is now viable.
-------
- **明確的 API**
  - 用 `createServerFn()` 跟 `renderServerComponent()` — 明確的 function call，不像 Next.js 用「檔案命名魔法」推斷哪些是 RSC。
- **Component 當 prop 的 pattern**
  - 把 React component 當 prop 傳給 RSC（不只是傳資料） — 組合方式很彈性，還有 `CompositeComponent` wrapper 可混用 server + client。
- **實際效能提升**
  - 範例：JS bundle 從 308KB 降到 203KB，把非互動邏輯推到 server 端。
- **server-only 資料**
  - RSC 可以直接 `await` DB 查詢 / API request — 不用中間的 API route，credential 也不會流到 client。
- **為什麼重要**
  - 這是 Next.js 之外第一個認真做的 RSC 替代方案。如果你想用 RSC 但不想被 Next.js 的 opinion 綁住，TanStack Start 現在可行了。

### TC39 Composites Proposal: `Composite.equal()` for JS
### TC39 Composites 提案：JS 終於有 `Composite.equal()`

[原文連結](https://frontendmasters.com/blog/arrays-objects-now-composites/)

- **The problem**
  - JS only has reference equality for objects: `{x:1} === {x:1}` is `false`. Every value comparison requires hand-rolled deep-equal or libraries.
- **The proposal**
  - `Composite.equal(pos1, pos2)` — value-based equality for composite types. Also usable as Map / Set keys.
- **Practical impact**
  - Eliminates a whole class of bugs around comparing positions, coordinates, config objects. Frameworks that depend on referential equality (React `useMemo`) get a more ergonomic API.
- **Status**
  - Proposal stage; track on TC39 to see when it reaches stage 4 / ships in V8.
-------
- **問題**
  - JS 對物件只有 reference equality：`{x:1} === {x:1}` 是 `false`。每次比較值都要手寫 deep-equal 或用 library。
- **提案內容**
  - `Composite.equal(pos1, pos2)` — composite 型別的值比較。也能拿來當 Map / Set 的 key。
- **實際影響**
  - 砍掉一整類 bug：比較座標、位置、設定物件。依賴 reference equality 的框架（React `useMemo`）會有更好用的 API。
- **狀態**
  - 提案階段；追蹤 TC39 看何時進 stage 4 / 在 V8 上線。

## Glossary

- **RSC (React Server Components)**
  - React components that render only on the server, stream HTML + minimal JS to the browser, and can directly access databases / APIs without exposing credentials.
  - 只在 server 端 render 的 React 元件，串流 HTML + 最少 JS 給瀏覽器，可以直接存取 DB / API 不會洩漏 credential。
- **CUDA-checkpoint**
  - Snapshotting GPU memory + CUDA execution state so a new replica can restore from a frozen image instead of re-initializing — saves seconds-to-minutes of device setup.
  - Snapshot GPU 記憶體 + CUDA 執行狀態，新 replica 從凍結映像還原而不是重做初始化 — 省下幾秒到幾分鐘的裝置設定時間。
- **C/R (Checkpoint/Restore)**
  - A Linux-level technique (CRIU and friends) that freezes a running process's full memory and state to disk, allowing instant restoration later.
  - Linux 層的技術（CRIU 之類），把正在跑的 process 完整記憶體與狀態凍結到磁碟，事後瞬間還原。
- **FUSE (Filesystem in Userspace)**
  - A Linux interface for implementing filesystems in user code instead of kernel — used by Modal for lazy-loaded container image layers with tiered caching.
  - 在 user-space 實作 filesystem 的 Linux 介面（不用寫 kernel） — Modal 用它做 lazy load 跟分層快取的 container image。
- **Stainless**
  - SDK / CLI / MCP-server generator (now Anthropic) that produces idiomatic client libraries for APIs across many languages (TS, Python, Go, Java, Kotlin).
  - SDK / CLI / MCP-server 生成器（現屬 Anthropic），為 API 在多語言（TS、Python、Go、Java、Kotlin）產出 idiomatic 的 client library。
- **Eval-Driven Development**
  - The "AI Engineer" workflow: define automated evaluations for LLM output quality, then iterate prompts / tools / models against the evals like a test suite.
  - 「AI Engineer」的工作流：先為 LLM 輸出品質定義自動化 eval，然後像跑 test suite 一樣對著 eval 迭代 prompt / tool / model。
- **TC39 Composites**
  - A JavaScript proposal adding value-based equality for composite types (objects, arrays) — fixes the long-standing issue that `{x:1} === {x:1}` is `false`.
  - JavaScript 提案，為 composite 型別（物件、陣列）加上值比較 — 解決長久以來 `{x:1} === {x:1}` 是 `false` 的問題。
- **View Transitions API**
  - A browser API for animating between page / DOM states (including SPA navigation) using CSS pseudo-elements — no manual position measurement.
  - 用 CSS pseudo-element 做頁面 / DOM 狀態之間動畫（包括 SPA 導航）的瀏覽器 API — 不用手動量位置。
- **Agent Skill**
  - A reusable, sandboxed capability bundle (a `skill.md` plus allowed tools / file scopes) that AI coding agents install and invoke on demand.
  - 可重用、沙箱化的能力包（一份 `skill.md` 加允許工具 / 檔案範圍），AI coding agent 按需安裝呼叫。
