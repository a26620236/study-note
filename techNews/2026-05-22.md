### Indexing a Year of Video Locally on a 2021 MacBook
### 2021 年 MacBook 一個週末本地索引完一整年的影片

[原文連結](https://blog.simbastack.com/indexed-a-year-of-video-locally/)

- **The pipeline (~1,400 lines of Python)**
  - **ffmpeg** extracts 5 frames per clip at 1920px.
  - **WhisperX** transcribes (97 languages, speaker diarisation).
  - **ArcFace** embeddings into SQLite for cross-archive face queries.
  - **Gemma 4 31B Q4** in LM Studio writes structured `.description.md` sidecars per clip.
  - GPS + reverse-geocoding + enum-constrained metadata baked in.
- **Hardware**
  - 2021 M1 Max, 64GB RAM. Peak 50.89GB swap; Gemma 4 31B Q4 consumes 28.4GB in memory.
  - Apple swap held up despite aggressive resource use.
- **Lessons**
  - **Schema over prose** — enum-constrained fields beat open-ended instructions for reducing hallucination on bulk metadata.
  - **Local-first scales** for indexing — a 31B local model produces near-cloud quality at zero per-call cost.
  - **Index precedes editing** — the real bottleneck wasn't editing software, it was making the archive queryable in natural language.
-------
- **流水線（約 1,400 行 Python）**
  - **ffmpeg** 每段影片抽 5 張 1920px frame。
  - **WhisperX** 轉錄（97 語言、speaker diarisation）。
  - **ArcFace** embedding 存 SQLite，做跨檔案的人臉查詢。
  - **Gemma 4 31B Q4** 跑在 LM Studio，為每段影片寫出結構化的 `.description.md` 描述檔。
  - GPS、地點反查、用 enum 限制的欄位 metadata 都串好。
- **硬體**
  - 2021 M1 Max、64GB RAM。峰值用到 50.89GB swap；Gemma 4 31B Q4 在記憶體中佔 28.4GB。
  - Apple 的 swap 在重負載下撐住了。
- **教訓**
  - **用 schema 而不是 prose**：批次產 metadata 時，用 enum 限制欄位比開放式指令更能壓住幻覺。
  - **本地優先可規模化**：31B 本地模型搭結構化 prompt，產出接近雲端品質、每次呼叫零成本。
  - **先索引再編輯**：真正的瓶頸不是剪輯軟體，是讓檔案能用自然語言查詢。

### Python 3.15: The Features That Didn't Make the Headlines
### Python 3.15：那些沒被頭版報導的小更新

[原文連結](https://blog.changs.co.uk/python-315-features-that-didnt-make-the-headlines.html)

- **Async**
  - `TaskGroup.cancel()` — graceful cancellation of concurrent tasks without custom exception handling.
  - `ContextDecorator` now correctly wraps async functions, async iterators, and generators.
- **Threading**
  - `threading.serialize_iterator` — prevents iterator race conditions.
  - `threading.synchronized_iterator` decorator — applies serialisation automatically.
  - `threading.concurrent_tee` — duplicate values across iterators safely.
  - Net effect: less reliance on Queue-based synchronisation for threaded code.
- **Stdlib niceties**
  - `collections.Counter` gains XOR (symmetric difference) — completes set-like operations.
  - `json.load(s)` adds `array_hook`; pair with `frozendict` for fully immutable JSON parsing.
-------
- **非同步**
  - `TaskGroup.cancel()` — 優雅取消並行任務，不必再自寫例外處理。
  - `ContextDecorator` 現在能正確包裝非同步函式、async iterator 與 generator。
- **執行緒**
  - `threading.serialize_iterator` — 防止 iterator 競爭條件。
  - `threading.synchronized_iterator` decorator — 自動套用序列化。
  - `threading.concurrent_tee` — 安全地把同一個 iterator 的值複製給多個消費者。
  - 結果：執行緒程式碼不必再那麼依賴 Queue 來做同步。
- **stdlib 小幸福**
  - `collections.Counter` 新增 XOR（對稱差） — 補齊類 set 的運算。
  - `json.load(s)` 多了 `array_hook`；搭配 `frozendict` 可解析出完全不可變的 JSON。

### From Ubuntu 16.04 to FreeBSD Jails After 10 Years on the Same Box
### 同一台機器跑 Ubuntu 16.04 十年後，遷移到 FreeBSD jail

[原文連結](https://crocidb.com/post/this-blog-ran-on-ubuntu-16-04-for-10-years-i-migrated-it-to-freebsd/)

- **Motivation**
  - Ubuntu 16.04 stopped getting security updates years ago. Cost was $13/month on DigitalOcean; Hetzner FreeBSD at under €6/month is cheaper *and* gets better specs.
- **Architecture**
  - One Caddy reverse-proxy jail for TLS + domain routing.
  - One jail per site running nginx + Hugo.
  - PF firewall rules for NAT, virtual interface for jail networking.
  - ZFS snapshots for backups — no reliance on provider backup features.
- **The gotcha**
  - Couldn't handle 10k concurrent connections until raising `kern.ipc.somaxconn` from 128 → 16384.
- **Results**
  - Throughput: 833 → 12,260 req/sec.
  - Latency: 89ms → 6.75ms.
  - All measured across São Paulo / London / Silicon Valley / Tokyo probes.
-------
- **動機**
  - Ubuntu 16.04 已經幾年沒安全更新。DigitalOcean 上每月 $13；Hetzner 的 FreeBSD 每月不到 €6，價格更低、規格還更好。
- **架構**
  - 一個 Caddy 反向代理 jail，處理 TLS 與網域路由。
  - 每個站點一個 jail，跑 nginx + Hugo。
  - 用 PF firewall 配 NAT、用虛擬網卡做 jail 網路。
  - 用 ZFS snapshot 做備份 — 不依賴主機商的備份功能。
- **小坑**
  - 10k 並發連線時撐不住，把 `kern.ipc.somaxconn` 從 128 拉到 16384 才正常。
- **結果**
  - 吞吐量：833 → 12,260 req/sec。
  - 延遲：89ms → 6.75ms。
  - 從聖保羅／倫敦／矽谷／東京四地實測。

## Glossary

- **Sandboxed agent**
  - An agent running in an isolated environment whose access to production data, networks, and tools is bounded by policy — letting you run autonomous code without giving it production keys.
  - 跑在「政策圈定範圍」內的 agent — 其對 production 資料、網路、工具的存取都有上限；好處是可以放手自主執行，但又不會把 production key 交給它。
- **Agent skill**
  - A reusable, declarative instruction pack a coding agent loads to follow a specific workflow (TDD, security review, framework-specific patterns). Sets like `dotnet/skills` are first-party.
  - 一個可重用的宣告式指令包，agent 載入後遵循特定工作流程（TDD、資安審查、框架專屬模式）。`dotnet/skills` 這種屬於第一方。
- **MAUI (.NET)**
  - Microsoft's cross-platform UI framework for building native iOS / Android / Windows / macOS apps from a single C# codebase — successor to Xamarin.Forms.
  - 微軟跨平台 UI 框架，用一份 C# code base 同時做出原生 iOS／Android／Windows／macOS app — Xamarin.Forms 的後繼者。
- **TaskGroup (Python asyncio)**
  - Python 3.11+ primitive that runs a structured set of concurrent tasks; cancellation and exception handling are bounded to the group rather than leaking to the whole loop.
  - Python 3.11+ 的原語，用來跑一組結構化的並行任務；取消與例外處理被綁定在 group 內，不會外洩到整個 event loop。
- **PF (FreeBSD packet filter)**
  - FreeBSD's primary packet filter / firewall language — originally from OpenBSD — used here to NAT jail traffic and route by hostname.
  - FreeBSD 的主要封包過濾／防火牆語言（源自 OpenBSD）— 本文中用於 jail 流量的 NAT 與主機名稱路由。
- **FreeBSD jail**
  - FreeBSD's OS-level virtualisation primitive — like Linux containers but kernel-native — with shared kernel and isolated userland, filesystem, processes, and network.
  - FreeBSD 的 OS 層級虛擬化原語 — 概念類似 Linux container 但是 kernel 原生 — 共用 kernel、隔離 userland、檔案系統、行程與網路。
- **WhisperX**
  - An open-source speech-to-text pipeline built on OpenAI Whisper, adding speaker diarisation and word-level alignment — common backbone for local transcription.
  - 建在 OpenAI Whisper 上的開源 STT pipeline，增加 speaker diarisation 與字詞層級對齊 — 本地轉錄常用的骨幹。
- **ArcFace**
  - A face-recognition embedding model that maps a face image to a vector; cosine distance in that space ≈ "are these the same person?" — used here for cross-archive face search.
  - 把人臉影像對應到向量的人臉辨識 embedding 模型；向量空間中的 cosine 距離 ≈「這是不是同一個人？」 — 本文中用於跨檔案人臉搜尋。
- **`somaxconn` (kernel parameter)**
  - The maximum length of the listen queue for a socket — too low and high-concurrency servers drop SYNs even when CPU and memory are fine.
  - socket listen queue 的最大長度 — 設太低，即使 CPU 與記憶體都有餘裕，高並發伺服器也會丟掉新進連線。
